# Module 18 — Déploiement

> Front, backend, VPS, SSL et automatisation

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 30h |
| **Niveau** | Intermédiaire à Avancé |
| **Prérequis** | Module 14, Module 15 |

## Objectifs pédagogiques

1. Déployer un frontend sur Vercel, Netlify ou Cloudflare
2. Déployer un backend sur VPS, Railway ou Render
3. Configurer un serveur Linux (Ubuntu/Debian)
4. Installer et renouveler SSL avec Let's Encrypt
5. Automatiser le déploiement avec Coolify

## Chapitres (10)

1. Stratégies de déploiement
2. Déploiement frontend : Vercel
3. Déploiement frontend : Netlify et Cloudflare
4. Déploiement backend : Railway et Render
5. VPS : configuration Ubuntu
6. Nginx et reverse proxy en production
7. SSL avec Let's Encrypt
8. Coolify : PaaS self-hosted
9. Blue-green et rolling deployment
10. Rollback et disaster recovery

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP

5. Consulter les corrections si besoin
6. Évaluation finale
