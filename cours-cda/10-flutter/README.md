# Module 10 — Flutter

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 40h |
| **Niveau** | Intermédiaire |

## Objectifs pédagogiques

1. Comprendre le modèle Widget de Flutter
2. Gérer l'état (setState, Provider, Riverpod)
3. Implémenter la navigation multi-écrans
4. Consommer des APIs REST
5. Publier sur Android et iOS

## Chapitres (10)

1. Introduction à Flutter et Dart
2. Widgets Stateless et Stateful
3. Layouts et responsive
4. State management
5. Navigation et routing
6. Consommation d'API
7. Stockage local
8. Tests Flutter
9. Publication Android
10. Publication iOS

1. Lire `cours.html` intégralement

5. Consulter les corrections si besoin
