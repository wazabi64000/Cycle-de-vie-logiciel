# Module 01 — Analyse et conception

> Le module le plus important — 80 % des problèmes viennent d'une mauvaise conception

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 60h |
| **Niveau** | Débutant à Intermédiaire |
| **Prérequis** | Module 00 |

## Objectifs pédagogiques

1. Recueillir et formaliser un besoin client
2. Rédiger un cahier des charges structuré
3. Rédiger des User Stories au format standard
4. Modéliser avec UML (cas d'utilisation, classe, séquence, activité, état)
5. Concevoir une base de données (MERISE : MCD, MLD, MPD)
6. Réaliser des maquettes avec Figma ou Penpot

## Chapitres (10)

1. Recueil du besoin : client, utilisateur, problème, solution
2. Le cahier des charges
3. Les User Stories
4. UML — Diagrammes de cas d'utilisation
5. UML — Diagrammes de classes
6. UML — Diagrammes de séquence
7. UML — Diagrammes d'activité et d'état
8. MERISE et modélisation de données
9. Du MCD au MPD
10. Maquettage UI/UX avec Figma

## Structure du module

```
01-analyse-conception/
├── README.md          ← Ce fichier
├── cours.html         ← Cours complet (théorie + visualisations)
├── quiz.json          ← 20+ questions
├── exercices.json     ← Exercices par niveau
├── tp.json            ← Travaux pratiques
├── correction.json    ← Corrections détaillées
├── ressources.json    ← Ressources complémentaires
└── evaluation.json    ← Grille d'évaluation
```

## Progression recommandée

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP
4. Passer le quiz (seuil : 70 %)
5. Consulter les corrections si besoin
6. Évaluation finale
