# Module 17 — OSINT défensif

> Recherche d'informations et sécurité défensive

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 20h |
| **Niveau** | Intermédiaire |
| **Prérequis** | Module 13 |

## Objectifs pédagogiques

1. Comprendre l'OSINT dans une démarche défensive
2. Utiliser Whois, DNS et énumération de sous-domaines
3. Analyser l'exposition avec Shodan
4. Vérifier les security headers et fuites de données
5. Produire un rapport d'exposition

## Chapitres (10)

1. Introduction à l'OSINT défensif
2. Cadre légal et éthique
3. Whois et registres DNS
4. Énumération de sous-domaines
5. Shodan et exposition des services
6. Security Headers analysis
7. Leak checkers et fuites de credentials
8. Reconnaissance passive
9. Rapport d'audit OSINT
10. Durcissement post-audit
