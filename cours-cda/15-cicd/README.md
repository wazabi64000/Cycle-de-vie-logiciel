# Module 15 — CI/CD

> GitHub Actions et pipelines automatisés

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 25h |
| **Niveau** | Intermédiaire à Avancé |
| **Prérequis** | Module 03, Module 12, Module 14 |

## Objectifs pédagogiques

1. Comprendre les principes CI/CD
2. Créer des pipelines GitHub Actions complets
3. Automatiser lint, tests, build et deploy
4. Gérer les environnements (dev, staging, prod)
5. Implémenter le déploiement continu

## Chapitres (10)

1. Introduction CI/CD
2. GitHub Actions : concepts
3. Workflow : lint et formatage
4. Workflow : tests automatisés
5. Workflow : build et artifacts
6. Workflow : déploiement
7. Environnements et secrets
8. Matrix builds et parallélisation
9. Notifications et monitoring CI
10. Bonnes pratiques CI/CD

## Structure du module

```
15-cicd/
├── README.md          ← Ce fichier
├── cours.html         ← Cours complet (théorie + visualisations)
├── quiz.json          ← 20+ questions
├── exercices.json     ← Exercices par niveau
├── tp.json            ← Travaux pratiques
├── correction.json    ← Corrections détaillées
├── ressources.json    ← Ressources complémentaires
└── evaluation.json    ← Grille d'évaluation
```

## Progression recommandée

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP
4. Passer le quiz (seuil : 70 %)
5. Consulter les corrections si besoin
6. Évaluation finale
