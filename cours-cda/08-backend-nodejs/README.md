# Module 08 — Backend Node.js

> Express, authentification JWT et PostgreSQL

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 50h |
| **Niveau** | Intermédiaire à Avancé |
| **Prérequis** | Module 05, Module 06 |

## Objectifs pédagogiques

1. Créer une API REST avec Express
2. Structurer en Routes, Controllers, Services, Repositories
3. Implémenter JWT, Refresh Token et RBAC
4. Interagir avec PostgreSQL (jointures, transactions, index)
5. Optimiser les performances backend

## Chapitres (10)

1. Node.js et l'écosystème npm
2. Express : routes et middleware
3. Architecture en couches
4. Controllers et Services
5. Repository pattern avec PostgreSQL
6. Authentification JWT
7. Refresh Token et sessions
8. RBAC et autorisation
9. Validation et gestion d'erreurs
10. Optimisation et bonnes pratiques
