# Module 00 — Découverte du métier

> Comprendre l'écosystème du développement logiciel

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 20h |
| **Niveau** | Débutant |
| **Prérequis** | Aucun prérequis technique |

## Objectifs pédagogiques

1. Identifier les rôles clés d'une équipe de développement
2. Distinguer frontend, backend, fullstack, DevOps et QA
3. Comprendre le cycle de vie d'un logiciel
4. Rédiger une fiche métier et une roadmap personnelle
5. Définir des objectifs professionnels réalistes

## Chapitres (10)

1. Qu'est-ce que le développement logiciel ?
2. Le développeur frontend
3. Le développeur backend
4. Le développeur fullstack
5. Le DevOps engineer
6. Le QA / testeur
7. L'architecte logiciel
8. Le Product Owner et le Scrum Master
9. Le chef de projet IT
10. Construire sa roadmap de carrière

## Structure du module

```
00-introduction-metier/
├── README.md          ← Ce fichier
├── cours.html         ← Cours complet (théorie + visualisations)
├── quiz.json          ← 20+ questions
├── exercices.json     ← Exercices par niveau
├── tp.json            ← Travaux pratiques
├── correction.json    ← Corrections détaillées
├── ressources.json    ← Ressources complémentaires
└── evaluation.json    ← Grille d'évaluation
```

## Progression recommandée

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP
4. Passer le quiz (seuil : 70 %)
5. Consulter les corrections si besoin
6. Évaluation finale
