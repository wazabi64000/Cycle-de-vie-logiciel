|-----------|--------|

## Objectifs pédagogiques

1. Structurer une page avec header, main, aside, footer
2. Appliquer les normes WCAG et ARIA pour l'accessibilité
3. Optimiser le SEO technique
4. Créer des layouts responsive (Mobile First)
5. Maîtriser Flexbox et CSS Grid
6. Réaliser des animations avec transitions et keyframes
