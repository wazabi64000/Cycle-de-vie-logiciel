# Module 14 — DevOps

> Linux, Docker, Nginx et reverse proxy

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 40h |
| **Niveau** | Intermédiaire à Avancé |
| **Prérequis** | Module 03, Module 08 |

## Objectifs pédagogiques

1. Maîtriser les commandes Linux essentielles
2. Containeriser avec Docker (images, volumes, networks)
3. Orchestrer avec Docker Compose
4. Configurer Nginx et Traefik comme reverse proxy
5. Automatiser le déploiement d'infrastructure

5. Docker : volumes et networks
