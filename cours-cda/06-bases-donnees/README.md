# Module 06 — Bases de données

> Modélisation, SQL, PostgreSQL et optimisation

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 40h |
| **Niveau** | Intermédiaire |
| **Prérequis** | Module 01, Module 05 |

## Objectifs pédagogiques

1. Concevoir un schéma relationnel normalisé
2. Écrire des requêtes SQL complexes (jointures, sous-requêtes)
3. Utiliser PostgreSQL en production
4. Gérer les transactions et l'intégrité référentielle
5. Optimiser avec index et EXPLAIN ANALYZE

## Chapitres (10)

1. Introduction aux bases de données relationnelles
2. Modélisation et normalisation
3. SQL : CRUD et filtres
4. Jointures et agrégations
5. Sous-requêtes et CTE
6. Transactions et ACID
7. PostgreSQL : types, extensions, JSONB
8. Index et optimisation
9. Migrations et versioning de schéma
10. NoSQL : introduction et cas d'usage

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP
4. Passer le quiz (seuil : 70 %)
5. Consulter les corrections si besoin
6. Évaluation finale
