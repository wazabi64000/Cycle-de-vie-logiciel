# Module 13 — Sécurité applicative

> OWASP Top 10, authentification et sécurité API

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 35h |
| **Niveau** | Intermédiaire à Expert |
| **Prérequis** | Module 08, Module 06 |

## Objectifs pédagogiques

1. Maîtriser l'OWASP Top 10 en détail
2. Implémenter JWT, sessions, OAuth et 2FA
3. Sécuriser une API (rate limit, helmet, validation)
4. Prévenir les injections SQL et l'escalade de privilèges
5. Gérer les secrets de manière sécurisée

## Chapitres (10)

1. Introduction à la cybersécurité applicative
2. OWASP Top 10 — vue d'ensemble
3. Injection et XSS
4. Authentification cassée et gestion de session
5. JWT, OAuth 2.0 et 2FA
6. Sécurité API : rate limiting et helmet
7. Validation et sanitization
8. Injection SQL et ORM sécurisé
9. Gestion des secrets et variables d'environnement
10. Audit de sécurité et pentest défensif

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP

5. Consulter les corrections si besoin
6. Évaluation finale
