# Module 03 — Git, GitHub et GitLab

> Versionning, branching et collaboration en équipe

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 30h |
| **Niveau** | Débutant à Avancé |
| **Prérequis** | Module 00 |

## Objectifs pédagogiques

1. Comprendre pourquoi Git existe et quels problèmes il résout
2. Maîtriser les commandes Git essentielles
3. Appliquer Git Flow, GitHub Flow et Trunk Based Development
4. Créer et gérer des Pull Requests et Merge Requests
5. Effectuer des code reviews et résoudre les conflits

## Chapitres (10)

1. Pourquoi Git ? Histoire et problèmes résolus
2. Installation et configuration
3. Commits, branches et merges
4. Git Flow
5. GitHub Flow
6. Trunk Based Development
7. Pull Requests et code review
8. Résolution de conflits
9. GitLab CI et intégration
10. Bonnes pratiques en équipe

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP
4. Passer le quiz (seuil : 70 %)
