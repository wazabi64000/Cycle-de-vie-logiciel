Module 03 — Git, GitHub et GitLab

Versionning, branching et collaboration en équipe

⏱ 30h 📊 Débutant à Avancé 📚 10 chapitres

1. Introduction

Pourquoi ce sujet existe ?

Git est le standard universel de gestion de versions. Aucune entreprise ne recrute sans cette compétence.

Où intervient-il ?

À chaque ligne de code écrite, dans chaque pipeline CI/CD, sur chaque Pull Request.

Quels problèmes résout-il ?

Résout la perte de code, les versions concurrentes, le travail en parallèle et la traçabilité des modifications.

2. Théorie simplifiée

Définition simple

Git, GitHub et GitLab : compétence centrale du développeur d'applications moderne.

Définition métier

Attendue en entreprise pour contribuer à des projets logiciels en équipe.

Définition technique

10 chapitres progressifs, du concept à la pratique professionnelle.

Cas d'usage réels

  • Comprendre pourquoi Git existe et quels problèmes il résout
  • Maîtriser les commandes Git essentielles
  • Appliquer Git Flow, GitHub Flow et Trunk Based Development

  • Effectuer des code reviews et résoudre les conflits
