1. Introduction

Pourquoi ce sujet existe ?

JavaScript est le langage le plus utilisé au monde. Il anime le web, le mobile et le backend.

Où intervient-il ?

Frontend (React, Vue), backend (Node.js), mobile (React Native), desktop (Electron).

Quels problèmes résout-il ?

Résout l'interactivité web, la communication client-serveur et la logique métier côté client.
