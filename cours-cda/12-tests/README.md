# Module 12 — Tests logiciels

> Unitaires, API, E2E et couverture 80 %

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 35h |
| **Niveau** | Intermédiaire à Avancé |
| **Prérequis** | Module 05, Module 08 |

## Objectifs pédagogiques

1. Écrire des tests unitaires avec Jest et Vitest
2. Tester des APIs avec Supertest
3. Automatiser des tests E2E avec Playwright et Cypress
4. Atteindre 80 % de couverture de code minimum
5. Intégrer les tests dans le workflow de développement

## Chapitres (10)

1. Pourquoi tester ? Pyramide des tests
2. Tests unitaires avec Jest
3. Tests unitaires avec Vitest
4. Mocks, stubs et spies
5. Tests d'intégration API avec Supertest
6. Tests E2E avec Playwright
7. Tests E2E avec Cypress
8. Couverture de code et métriques
9. TDD : Test-Driven Development
10. Tests dans la CI/CD

## Progression recommandée

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP
4. Passer le quiz (seuil : 70 %)
5. Consulter les corrections si besoin
6. Évaluation finale
