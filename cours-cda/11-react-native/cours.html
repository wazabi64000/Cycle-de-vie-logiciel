Module 11 — React Native

Mobile cross-platform avec React

⏱ 40h 📊 Intermédiaire à Avancé 📚 10 chapitres

1. Introduction

Pourquoi ce sujet existe ?

React Native réutilise les compétences React pour le mobile, réduisant le temps d'apprentissage.

Où intervient-il ?

Applications mobiles iOS et Android, apps métier.

Quels problèmes résout-il ?

Résout le développement mobile rapide pour les équipes React existantes.

2. Théorie simplifiée

Définition simple

React Native : compétence centrale du développeur d'applications moderne.

Définition métier

Attendue en entreprise pour contribuer à des projets logiciels en équipe.

Définition technique

10 chapitres progressifs, du concept à la pratique professionnelle.

Cas d'usage réels

  • Développer des applications mobiles avec React Native
  • Configurer la navigation (React Navigation)
  • Gérer l'état avec Redux
  • Consommer des APIs et gérer les notifications
  • Publier sur les stores
