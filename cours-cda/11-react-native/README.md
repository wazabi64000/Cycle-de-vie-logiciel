# Module 11 — React Native

> Mobile cross-platform avec React

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 40h |
| **Niveau** | Intermédiaire à Avancé |
| **Prérequis** | Module 05, Module 09 |

## Objectifs pédagogiques

1. Développer des applications mobiles avec React Native
2. Configurer la navigation (React Navigation)
3. Gérer l'état avec Redux
4. Consommer des APIs et gérer les notifications
5. Publier sur les stores

## Chapitres (10)

1. Introduction à React Native
2. Composants natifs vs web
3. Styles et Flexbox mobile
4. React Navigation
5. Redux en mobile
6. Consommation d'API
7. Notifications push
8. Caméra et permissions
9. Performance mobile
10. Publication App Store et Play Store

## Progression recommandée

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP
4. Passer le quiz (seuil : 70 %)
5. Consulter les corrections si besoin
