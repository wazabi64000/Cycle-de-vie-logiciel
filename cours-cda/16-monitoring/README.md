# Module 16 — Monitoring et observabilité

> Logs, métriques, alertes et gestion d'erreurs

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 25h |
| **Niveau** | Intermédiaire à Avancé |
| **Prérequis** | Module 14, Module 15 |

## Objectifs pédagogiques

1. Configurer des logs structurés avec Winston et Pino
2. Mettre en place Grafana et Prometheus
3. Configurer des alertes proactives
4. Intégrer Sentry pour le suivi d'erreurs
5. Construire des dashboards de monitoring

## Chapitres (10)

1. Introduction à l'observabilité
2. Logs structurés avec Winston
3. Logs haute performance avec Pino
4. Métriques avec Prometheus
5. Dashboards Grafana
6. Alertes et seuils
7. Sentry : suivi d'erreurs
8. Tracing distribué — introduction
9. SLI, SLO et SLA
10. Incident response
