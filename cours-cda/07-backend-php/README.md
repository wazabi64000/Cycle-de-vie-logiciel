# Module 07 — Backend PHP moderne

> PHP 8+, architecture MVC et Laravel

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 50h |
| **Niveau** | Intermédiaire à Avancé |
| **Prérequis** | Module 05, Module 06 |

## Objectifs pédagogiques

1. Programmer en PHP 8+ avec typage strict
2. Appliquer l'architecture MVC, Services, Repository et DTO
3. Créer des middlewares et gérer l'authentification
4. Développer une API REST avec Laravel
5. Réaliser un projet complet Laravel

## Chapitres (10)

1. PHP 8+ : syntaxe moderne et typage
2. POO avancée en PHP
3. Architecture MVC
4. Services et Repository pattern
5. DTO et validation
6. Middleware et pipeline HTTP
7. Introduction à Laravel
8. Eloquent ORM et migrations
9. API REST avec Laravel
10. Projet Laravel complet

## Structure du module

```
07-backend-php/
├── README.md          ← Ce fichier
├── cours.html         ← Cours complet (théorie + visualisations)
├── quiz.json          ← 20+ questions
├── exercices.json     ← Exercices par niveau
├── tp.json            ← Travaux pratiques
├── correction.json    ← Corrections détaillées
├── ressources.json    ← Ressources complémentaires
└── evaluation.json    ← Grille d'évaluation
```

## Progression recommandée

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP
4. Passer le quiz (seuil : 70 %)
5. Consulter les corrections si besoin
6. Évaluation finale
