# Module 19 — Projet professionnel

> Marketplace type Elkoli — projet fil rouge complet

## Informations

| Propriété | Valeur |
|-----------|--------|
| **Durée** | 120h |
| **Niveau** | Avancé à Expert |
| **Prérequis** | Modules 01 à 18 |

## Objectifs pédagogiques

1. Concevoir et développer une marketplace complète
2. Implémenter auth, messagerie, paiement, notifications
3. Créer dashboard utilisateur et administration
4. Atteindre 80 % de couverture de tests
5. Déployer avec CI/CD, Docker et sécurité OWASP

## Chapitres (10)

1. Cahier des charges marketplace
2. Architecture technique
3. Modélisation base de données
4. API REST — authentification
5. API REST — annonces et recherche
6. API REST — messagerie temps réel
7. API REST — paiement et notation
8. Frontend React — catalogue et recherche
9. Frontend React — dashboard et admin
10. Tests, CI/CD, déploiement et documentation

## Structure du module

```
19-projet-professionnel/
├── README.md          ← Ce fichier
├── cours.html         ← Cours complet (théorie + visualisations)
├── quiz.json          ← 20+ questions
├── exercices.json     ← Exercices par niveau
├── tp.json            ← Travaux pratiques
├── correction.json    ← Corrections détaillées
├── ressources.json    ← Ressources complémentaires
└── evaluation.json    ← Grille d'évaluation
```

## Progression recommandée

1. Lire `cours.html` intégralement
2. Réaliser les exercices (débutant → expert)
3. Compléter les TP
4. Passer le quiz (seuil : 70 %)
5. Consulter les corrections si besoin
6. Évaluation finale
